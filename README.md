# Interactive Personal Blog

## Description

This is a simple blog app made with HTML, CSS, and JavaScript. Users can add, edit, and delete posts. Posts are saved in `localStorage`, so they stay after the page is refreshed.

## How to Run

1. Open the project folder in VS Code.
2. Open `index.html` with Live Server.
3. Add a title and post content.
4. Use the Edit and Delete buttons to manage posts.

## Reflection

This project helped me practice DOM manipulation, event listeners, form validation, and `localStorage`. One challenge was editing the correct post without creating a new one. I solved this by using the post ID to find and update the right post. I also learned how to save changes in `localStorage` so posts stay after refreshing the page.
